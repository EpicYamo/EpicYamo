# Arda Aycan

Software engineering student working through the 42 school curriculum.
Most of what I build sits close to the system: C, Linux, sockets, and the point
where software has to talk to hardware.

## Featured projects

**[ophis](https://github.com/EpicYamo/ophis)** — a Linux control centre for the
Razer Blade 14 (2022): performance profiles, fan curves, per-key RGB animations,
battery charge limit and a tray app. GTK4/libadwaita, no kernel module, no
daemon, no vendor account.

**[PrismRT](https://github.com/EpicYamo/PrismRT)** — a CPU ray tracer with a
real-time scene editor: Phong lighting, XPM textures, bump mapping, gizmos,
undo/redo and a handful of extra primitives. C and MiniLibX.

**[ft_irc](https://github.com/EpicYamo/ft_irc)** — an IRC server in C++98 with a
single `poll()` loop, non-blocking sockets, channels and modes, a DCC relay and a
small companion bot.

**[minishell](https://github.com/EpicYamo/minishell)** — a Bash-like shell in C:
lexer, parser and executor with pipes, redirections, heredocs, quotes and
environment handling.

**[philosophers](https://github.com/EpicYamo/philosophers)** — the dining
philosophers with threads (mutexes) and with processes (named semaphores),
including death detection without shared memory.

**[BetterRGB](https://github.com/EpicYamo/BetterRGB)** — per-key RGB control for
Tongfang/ITE8291 gaming laptops, reverse-engineered from USB traffic and written
from scratch in C for Windows.
